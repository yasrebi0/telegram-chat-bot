# بات تلگرام گفتگوی روزمره

یک بات تلگرام ساده و سبک برای چت معمولی و گپ زدن درباره‌ی روزمرگی، نوشته‌شده با
Telegram Bot API خالص (بدون کتابخانه‌ی سنگین) و کاملاً سازگار با اجرای **سرورلس** (Vercel Functions).

اگر کلید Anthropic (Claude) را تنظیم کنید، بات پاسخ‌های هوشمند و طبیعی تولید می‌کند؛
در غیر این‌صورت از یک موتور پاسخ‌دهی ساده‌ی فارسی استفاده می‌شود.

## ساختار پروژه

```
telegram-chat-bot/
├── api/
│   └── webhook.js       # نقطه‌ورود سرورلس - تلگرام آپدیت‌ها را اینجا POST می‌کند
├── lib/
│   ├── telegram.js       # توابع ارتباط با Telegram Bot API
│   └── chat.js           # منطق تولید پاسخ (Claude یا حالت ساده)
├── scripts/
│   └── set-webhook.js    # اسکریپت ثبت آدرس وبهوک بعد از دیپلوی
├── vercel.json
├── package.json
└── .env.example
```

## مرحله ۱: ساخت بات در تلگرام

۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
۲. دستور `/newbot` را بزنید و اسم و یوزرنیم بات را انتخاب کنید.
۳. توکنی که می‌دهد (چیزی شبیه `123456789:AAExample...`) را نگه دارید.

## مرحله ۲: دیپلوی روی Vercel (سرورلس)

۱. یک ریپازیتوری گیت‌هاب با همین فایل‌ها بسازید و کد را در آن push کنید.
۲. در [vercel.com](https://vercel.com) پروژه را از روی همان ریپو Import کنید.
۳. در بخش **Environment Variables** پروژه، این متغیرها را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` → توکنی که از BotFather گرفتید
   - `ANTHROPIC_API_KEY` → (اختیاری) برای پاسخ‌های هوشمند با Claude
   - `TELEGRAM_WEBHOOK_SECRET` → (اختیاری) یک رشته‌ی دلخواه برای امنیت بیشتر
۴. روی Deploy بزنید. آدرس نهایی چیزی مثل `https://your-project.vercel.app` خواهد بود.

> می‌توانید به‌جای Vercel از هر پلتفرم سرورلس دیگری (Netlify Functions، AWS Lambda،
> Cloudflare Workers) هم استفاده کنید؛ فقط کافیست تابع `handler` در `api/webhook.js`
> را با فرمت مورد نیاز همان پلتفرم Wrap کنید. منطق اصلی (`lib/telegram.js` و
> `lib/chat.js`) بدون تغییر قابل استفاده است.

## مرحله ۳: معرفی آدرس به تلگرام (ثبت Webhook)

بعد از دیپلوی، این دستور را به‌صورت لوکال اجرا کنید تا تلگرام بداند آپدیت‌ها را کجا بفرستد:

```bash
npm install
TELEGRAM_BOT_TOKEN=توکن_شما \
PUBLIC_URL=https://your-project.vercel.app \
TELEGRAM_WEBHOOK_SECRET=رشته_دلخواه \
node scripts/set-webhook.js
```

اگر پیام `"ok": true` دریافت کردید، بات فعال است. حالا به تلگرام بروید و برای بات
پیام `/start` بفرستید.

## نکته‌ی مهم درباره‌ی حافظه‌ی گفتگو

توابع سرورلس بین درخواست‌ها معمولاً state را نگه نمی‌دارند (هر بار ممکن است یک
نمونه‌ی تازه اجرا شود)، بنابراین حافظه‌ی فعلی در `lib/chat.js` **موقتی** است و ممکن
است گاهی ریست شود. اگر می‌خواهید بات تاریخچه‌ی کامل گفتگو را همیشه به‌خاطر بسپارد،
در انتهای فایل `lib/chat.js` یک نمونه‌ی آماده برای اتصال به [Upstash Redis](https://upstash.com/)
(یک دیتابیس رایگان و سازگار با سرورلس) به‌صورت کامنت گذاشته‌ام؛ کافی‌ست پکیج
`@upstash/redis` را نصب کرده و آن بخش را جایگزین کنید.

## تست محلی (اختیاری)

برای تست بدون دیپلوی، می‌توانید از [ngrok](https://ngrok.com/) برای اکسپوز کردن
سرور لوکال استفاده کنید و همان آدرس ngrok را به‌جای `PUBLIC_URL` در اسکریپت
`set-webhook.js` بدهید. برای اجرای لوکال یک سرور HTTP ساده لازم دارید که
`api/webhook.js` را serve کند (مثلاً با `vercel dev`).

```bash
npm i -g vercel
vercel dev
```

## سفارشی‌سازی لحن بات

برای تغییر شخصیت و لحن بات، متغیر `SYSTEM_PROMPT` در ابتدای فایل `lib/chat.js`
را ویرایش کنید.
